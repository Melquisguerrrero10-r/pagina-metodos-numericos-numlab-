Módulo 1

¿Qué es un Método Numérico y cómo se representan en el Computador?

Un método numérico es un procedimiento matemático formulado para resolver problemas mediante operaciones aritméticas. Permite aproxima soluciones numéricas a problemas complejos donde una solución analítica exacta es difícil o imposible de obtener.

Representación en el Computador

Las computadoras tienen una memoria finita. Por ello, no pueden representar todos los números reales del continuo de forma exacta. Los números se almacenan utilizando el sistema binario (base 2) con un número fijo de bits.

Conversor Decimal a Binario (Enteros):
Binario: 101010₂

Aritmética de Punto Flotante

Para manejar cantidades extremadamente grandes o muy pequeñas, la computación utiliza la representación en Punto Flotante (estándar IEEE 754), dividiendo el espacio de memoria en:

Signo (1 bit)
Exponente (8/11 bits)
Mantisa (23/52 bits)
Módulo 2

Calculadora y Simulador de Teoría de Errores

Ingresa un Valor Real ($V$) y un Valor Aproximado ($V^*$) para calcular cuantitativamente las desviaciones numéricas.

Error Absoluto ($E_a$) |V - V*|
0.00159265
Error Relativo ($E_r$) |V - V*| / |V|
0.00050695
Error Porcentual ($E_p$) E_r × 100%
0.050695 %

Error por Truncamiento

Se produce cuando un proceso matemático infinito (como una serie de Taylor) se interrumpe antes de llegar al resultado final. Ejemplo: aproximar π ≈ 3.1415 descartando los dígitos siguientes sin ajustar.

Error por Redondeo

Surge debido al límite de bits en el computador. Los números con demasiados decimales se ajustan al valor más cercano almacenable. Ejemplo: 2/3 ≈ 0.666667.
